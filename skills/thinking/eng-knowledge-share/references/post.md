# Post format: all-engineering channel

My voice: conversational, positive, plain. Uses "I think", "for now", "if we are aligned". Not corporate. No AI polish, no praise, no filler, no emoji.

## Shape (under 120 words)

```
Sharing this about <topic in plain words>. I think it can help us <concrete benefit>.

<link to page>

<The idea in 2-3 plain sentences. Soft claims use "seems to" / "tends to".>

I think what I've found useful is <one practical action>.
   (or: What I'd suggest trying is <one practical action>.)

<Optional: Curious if anyone has tried this already.>
```

## Example (my own post, use as the voice reference)

> Sharing this about the "smart zone" of AI coding agents. I think it can help us save tokens and avoid redoing work.
>
> <link to page>
>
> The idea is that an agent's output quality gradually drops as a session gets longer, even if the context window isn't full yet. Roughly the first ~100k tokens seem to be where it follows instructions best. Starting a fresh session with a clear handoff, such as a plan or spec in a file, tends to produce better results than continuing one long session.
>
> I think what I've found useful is creating a handoff, then letting a new session continue the work, or using sub-agents if the task can be broken down into smaller pieces.

## Rules

- Keep `<link to page>` as a literal placeholder.
- One action only in the last paragraph.
- No source attribution in the post unless the input asks for it.
